About

A decentralized civic tech solution designed to bridge communication gaps between daily motorists, pedestrians, and public road administration.

System Objectives

Potholes, broken street lighting, and hazardous pavement cracks remain major contributors to roadway accidents. Conventional phone call desks often suffer from poor documentation, absent photographic evidence, and zero tracking mechanisms for citizens.

This platform introduces an accountable, transparent lifecycle where any citizen can submit an image, document coordinates, and monitor municipal mitigation progress in real time.

Technical Architecture

  • Client-Side Processing: Written strictly in standardized HTML5, CSS3, and modern Vanilla JavaScript without external dependencies.
  • Image Encoding: Converts user-submitted binary photos into Base64 strings using the native HTML5 FileReader API.
  • Offline-First Persistence: Utilizes browser localStorage to store serialized complaint JSON arrays and sequential ticket counters.
  • Lifecycle Tracking: Employs dynamic state management to advance tickets from Reported to Resolved.
